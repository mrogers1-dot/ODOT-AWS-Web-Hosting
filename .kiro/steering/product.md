# Product Overview

This project provisions and manages web hosting infrastructure on AWS. It defines the cloud resources, configuration, and deployment pipelines needed to host web applications or static sites on AWS services.

## Purpose

- Automate the creation and management of AWS hosting infrastructure
- Provide repeatable, version-controlled infrastructure deployments
- Support scalable, secure, and cost-efficient web hosting on AWS

## Key Goals

- Infrastructure as Code (IaC) for all AWS resources
- Minimal manual configuration — everything should be reproducible from code
- Clear separation between environments (e.g., dev, staging, prod)
